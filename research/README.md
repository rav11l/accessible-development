# WP-2026-10 версия 2.0
Общество доступного развития. Автор: Равиль Ахтямов. 17 ноября 2026 года.

Полный текст: https://digitaleconomylab.ru/wp-2026-10 и ../WP-2026-10.html. Название исходной работы сохранено.
Статус: концептуально-методологическое исследование. Новых эмпирических причинных оценок нет.

## Что изменилось
- Международные ориентиры отделены от авторских предложений и эмпирических доказательств.
- Культурная свобода и научно-техническая способность получили отдельные измерения.
- Добавлены три связанных направления оценки и паспорт девяти показателей.
- Уточнены общественные издержки, бюджетные трансферты и связь экспорта с инвестициями.
- Проверены поэтапное освоение, потери и замена оборудования.
- Раздел 10 посвящён научной фантастике СССР и Восточной Европы: Ефремову, Стругацким и Лему, в том числе «Футурологическому конгрессу».
- Добавлены источники 24–48. Литературные интерпретации не объявляются доказательствами хозяйственной эффективности.
- Четыре исходных рисунка и исторический срез 2024 года сохранены.

## Воспроизведение
Python 3.10+. Для расчётов достаточно стандартной библиотеки.
Запуск из папки комплекта: python reproduce.py
Результаты записываются в calculated/. Встроенные проверки завершаются ошибкой при несогласованности основных формул.
Дополнительно: python reproduce.py --plots создаёт графики, если установлен matplotlib.
Все деньги условные, в постоянных ценах. Параметры не оценены по наблюдениям.
Для EGDI: data_egdi_2024.csv, первоисточник [11] в исследовании.
При изменении параметров текст исследования автоматически не обновляется: нужна новая сверка.
